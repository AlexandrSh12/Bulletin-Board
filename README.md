# NauJava Bulletin Board
ПРАКТИЧЕСКАЯ РАБОТА № 7
Многопоточность и асинхронность

Для получения отчёта:

1. Запустить приложение, войти в систему как админ
2. Создать отчёт: POST /custom/reports/create (через Swagger или напрямую)
3. В ответе получить id отчёта
4. Открыть в браузере `http://localhost:8080/custom/reports/{id}`
5. Отобразится HTML-страница, удовлетворяющая всем требованиям задания
