# NauJava Bulletin Board
ПРАКТИЧЕСКАЯ РАБОТА № 8
Автоматизированное тестирование

## Тесты

### Unit-тесты (UserServiceImplTest)
Тестируют сервис пользователей с помощью Mockito:
- добавление нового пользователя
- попытка добавить уже существующего пользователя
- получение пользователя по имени
- получение несуществующего пользователя

### REST-тесты (ItemControllerTest)
Тестируют эндпоинты контроллера объявлений с помощью RestAssured:
- поиск объявлений по диапазону цен
- поиск комментариев по id объявления

### UI-тесты (LoginSeleniumTest)
Тестируют интерфейс через браузер с помощью Selenium:
- успешный вход в систему
- выход из системы

Запустить все тесты: `mvn test`

Selenium тесты запускать при остановленном приложении - они поднимают его сами.
